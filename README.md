# 🏨 MERN Hotel Booking Application

A full-stack hotel booking system built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
This application simulates a real-world hotel booking platform where users can book rooms, receive email confirmations, cancel bookings within a limited time, and administrators can manage the entire system through a powerful dashboard.

## ✨ Features

### 👤 User Features
- User Registration & Login Authentication (JWT)
- Secure Logout System
- Update User Profile
- Book Hotel Rooms
- Cancel Booking (within 10 minutes of booking)
- Email Notification after successful booking
- View Personal Booking History

---

### 🛠️ Admin Dashboard
- Secure Admin Login / Logout
- Create & Manage Hotels
- Create & Manage Rooms
- View All Bookings
- View All Users
- View User Booking Details
- Block / Unblock Users
- Role-Based Access Control
